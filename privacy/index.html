Folio for Canvas: Privacy Policy

Last updated September 27, 2026

Folio for Canvas is a browser extension that saves the files from your Canvas courses into folders you choose on your own computer. It does not collect, store, or transmit any personal data.

What the extension accesses

It connects only to your school's Canvas site (an instructure.com address) and to Instructure's file servers, using the Canvas login already in your browser. It reads your course list, course modules, pages, assignments, announcements, syllabus, and file details in order to find and download your course files. It only reads; it never changes anything in Canvas.

What is stored, and where

Downloaded files are saved only to folders you choose on your own computer. The extension also keeps, inside your browser, which folder each course uses and a list of files it has already saved, so nothing is downloaded twice. This information never leaves your computer.

What is shared

Nothing. The extension sends no data to the developer or to anyone else. There are no analytics, tracking, advertising, or third-party services.

Optional Mac helper (Firefox)

Firefox users on a Mac can optionally install a small helper program to save files into any folder. It only writes files into the folders you picked, never replaces or deletes existing files, and sends nothing anywhere.

Contact

Questions about this policy can be sent through the contact details on the extension's store listing.
